# Kyle Gulapa — Portfolio

A single-page portfolio for Kyle Gulapa, led by AI ad creative, UGC-style product videos, and stylized 3D ads. Development and business automation work provide supporting technical context.

## Local development

```bash
npm ci
npm run dev
```

Open the local URL printed by Next.js.

## Verification

```bash
npm run typecheck
npm run lint
npm run build
```

Presentation settings—including navigation, featured work, ordering, filters, metrics, contact links, capabilities, poster paths, and media behavior—live in `src/data/portfolio.ts`. Factual project, experience, skill, and film records remain in their dedicated typed modules under `src/data`.
